## 这是什么

艾宾浩斯记忆系统是一个 **Codex Desktop 记忆插件（Skill）**。它借鉴了心理学中的艾宾浩斯遗忘曲线原理——人类会自然遗忘不常回忆的信息，而重要的记忆会随时间沉淀。

AI 也一样：它不需要记住所有对话，只需要记住**重要的**。本插件模拟了这个过程：

- **刚说过的话** → 完整保留（短期记忆）
- **3 天后** → 自动压缩，删除仅提及一次的内容（遗忘开始）
- **1 周后** → 只保留核心事件和情绪（中等强度记忆）
- **1 个月后** → 极简四要素：时间 + 人物 + 事件 + 情绪（长期记忆）

## 为什么选择我们

🧠 **模拟人类遗忘曲线**
不是简单的日志记录，而是按照艾宾浩斯遗忘曲线的规律，让 AI 像人一样自然遗忘不重要的信息，保留关键记忆。

📄 **人类可读**
所有记忆卡都是纯 Markdown 格式，任何人都能直接阅读和编辑。不需要专门的工具来查看或管理。

💪 **不挑设备、不吃性能**
本地运行，不需要 GPU、不需要联网、不需要额外的计算资源。一个文本文件就是一张记忆卡。

🔒 **100% 本地存储**
所有数据保存在你的电脑上，不上传到任何服务器。你的记忆只属于你。

## 安装方法

1. 将本仓库放到 Codex 的 skills 目录下：

```bash
cp -r ebbinghaus-memory ~/.codex/skills/
```

2. 重启 Codex Desktop，skill 会自动加载

## 工作原理

```
对话开始 → 创建/读取当天记忆卡
    ↓
对话过程中 → 实时记录关键信息
    ↓
3天后 → 压缩至 500-1000 tokens，删除仅提及1次的内容
    ↓
1周后 → 移动到 month 文件夹，压缩至 300-500 tokens
    ↓
1月后 → 移动到 year 文件夹，压缩至 200 tokens，保留核心四要素
```

### 艾宾浩斯遗忘曲线对照

| 时间间隔 | 遗忘率（人类） | AI 记忆处理 | 保留内容 |
|---------|--------------|------------|---------|
| 即时 | ~0% | 完整记录 | 原话 + 情绪 + 环境 |
| 1天 | ~60% | 完整保留 | 全部 |
| 3天 | ~75% | 开始压缩 | 重复20次+、标记"重要"的 |
| 1周 | ~80% | 移动+压缩 | 核心事件、主要情绪、关键人物 |
| 1月 | ~90% | 极简保留 | 时间+人物+事件+情绪 |

### 记忆卡存储结构

```
~/Documents/memory-card/
├── weak/          # 一周内的记忆卡（完整版）
│   └── 08-15.md
├── month/         # 超一周未满一月（压缩版）
│   └── 08-10--项目讨论·压力大.md
└── year/          # 超过一月（极简版）
    └── 2026-07-15--与老板谈加薪·焦虑.md
```

### 记忆卡格式

```markdown
# 记忆卡
- 日期：2026-08-15
- 创建时间：14:30 (北京时间)
- 最后更新：16:45 (北京时间)
- 重要标签：#工作 #项目A #截止日期

## 记录内容
----14:30 用户说：项目A的截止日期提前了，压力很大---
----15:00 用户说：小王也遇到了同样的问题---
----16:45 用户重复：第3次提到截止日期---
```

## 检索方式

当你在对话中提到以下关键词时，系统会自动检索相关记忆卡：

- "之前说过"、"以前"、"上次"、"记忆"、"记得吗"
- 提到特定的时间、人物或事件

## 隐私说明

- 所有记忆卡存储在你的 **本地电脑** 上，不会上传到任何服务器
- 严格遵循「真实记录」原则：只记录你说过的话，不添加推测
- 你可以随时查看、编辑或删除任何记忆卡文件
